## Fixed

- **Glow screenshot during the entrance (journey).** Since U3, the glow's code word and We met rise in about 1.5 s after the color fills the screen, but they're in the accessibility tree at opacity 0 from the start, so the journey's "glowing" screenshot was a plain colored screen. The test now waits 2.5 s before that screenshot (`GlowA.settle()`). The assertions are unchanged; it also attaches the deck and the tap confirmation now.
- **Flaky FeatureGlow `state .loading` snapshot (2 cases).** `GlowLoadingView` drew its breath from a live `TimelineView`. It now takes the screen's `frozenAt` and draws the breath still when a snapshot sets it. The app is unchanged; the existing reference images already match.
- **Flaky FeatureMatch `waiting` snapshot (2 cases, found here).** The first confirming unit run failed only on Match `waiting` (default and AX5): `MomentBreathing` (the light behind the countdown) also ran a live `TimelineView`. It now holds the breath at `matchClockOverride` when a snapshot sets it. Re-recorded those two (looked at: same layout and copy; only the light behind the clock differs).
- **Hairline outside secondary capsule buttons (U1).** `GlowButtonBody` stroked a continuous-style `Capsule`; that path doubles back along a short straight segment at each end, so the 1 pt border and the top highlight drew a thin vertical line just outside both ends (visible on "Just chat", "Back to the match", Glow AX5, and faintly on primary buttons). The button shape is now a circular capsule. Re-recorded only the 79 snapshots whose pixels changed (a pixel diff against the committed images: every change sits inside a button band, at the ends or in the soft light under filled buttons; 7 re-rendered images were pixel-identical and were left alone). Looked at Match choosing, Chat not open and Glow canceled AX5 before and after: the line is gone, the ends are round.
- `scripts/agent-env.sh`: row `R1 72`.
